# Sand To Pharmacist

แอปวางแผนติวเข้มก่อนสอบปลายภาค จัดเวลาอ่านหนังสืออัตโนมัติจากตารางเรียนและตารางสอบ

## ทำอะไรได้บ้าง
- จัดช่วงอ่าน (50 นาที + พัก 10 นาที) ลงในเวลาว่างจากตารางเรียน
- ให้น้ำหนักวิชาที่สอบใกล้ ไม่มั่นใจ และเนื้อหาเหลือเยอะก่อน
- ติ๊กช่วงที่อ่านเสร็จ แล้วกด ง่าย / พอได้ / ยาก เพื่อปรับเวลาของวิชานั้น
- ทบทวนความจำแบบเว้นระยะ 1, 3, 7 วัน หลังอ่านแต่ละบท
- แก้ตารางเรียนประจำสัปดาห์ งดคาบ หรือเพิ่มคาบชดเชยเฉพาะวันได้
- ตั้งจำนวนช่วงอ่านของแต่ละวันในสัปดาห์ หรือปรับ − / + เฉพาะวัน
- เลื่อนเวลา เปลี่ยนวิชา ลบ หรือเพิ่มช่วงอ่านเองได้
- จัดแผนใหม่เมื่อมีช่วงอ่านที่พลาดไป

ติดตั้งลงหน้าจอโฮมได้เหมือนแอปทั่วไป และเปิดได้แม้ไม่มีเน็ต

ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage) ไม่มีเซิร์ฟเวอร์

## เปิดใช้งานด้วย GitHub Pages
1. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้น repository
2. ไปที่ Settings → Pages
3. Source เลือก "Deploy from a branch", Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## ติดตั้งลงหน้าจอโฮม
- **Android (Chrome):** เปิดลิงก์แอป กดปุ่ม "ติดตั้งแอป" มุมขวาบน หรือเมนู ⋮ → "เพิ่มลงในหน้าจอหลัก" / "ติดตั้งแอป"
- **iPhone / iPad (Safari):** เปิดลิงก์แอปใน Safari กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

## ไฟล์ในโปรเจกต์
- `index.html` ตัวแอป
- `manifest.webmanifest` ชื่อ ไอคอน และสีของแอปเวลาติดตั้ง
- `sw.js` ทำให้แอปเปิดได้ตอนออฟไลน์ (อัปเดตแอปเมื่อไร ให้เปลี่ยน `sand2pharm-v1` เป็นเลขใหม่)
- `` โลโก้ขนาดต่าง ๆ ถ้าจะเปลี่ยนโลโก้ ให้แทนไฟล์ PNG โดยใช้ชื่อและขนาดเดิม
