# Sand To Pharmacist
ทุกเม็ดทรายที่ไหลผ่าน เหมือนเข็มแห่งกาล สู่เภสัชกร

แอปวางแผนอ่านหนังสือก่อนสอบสำหรับนักศึกษาเภสัชศาสตร์ (PWA ไฟล์เดียว) โดย ปรุงยาเภสัช

## ทำอะไรได้บ้าง
- จัดช่วงอ่านลงเวลาว่างจากตารางเรียน ให้น้ำหนักวิชาที่สอบใกล้ ไม่มั่นใจ และเนื้อหาเหลือเยอะก่อน
- ติ๊ก และกด ง่าย / พอได้ / ยาก เพื่อปรับแผนระดับบท ทบทวนแบบเว้นระยะ 1, 3, 7 วัน
- งานที่ต้องส่ง: Lab report, รายงาน, Quiz, นำเสนอ, งานกลุ่ม · ส่งผ่าน MS Teams · คะแนนเก็บ
- ตารางเรียนแก้ได้ งดคาบ / เรียนชดเชยเฉพาะวัน · จำนวนช่วงอ่านต่อวัน
- ธีมสี 8 แบบ + โหมด ตามเครื่อง / สว่าง / มืด
- 📤 ส่งรายงาน 7 วันให้ผู้ปกครอง (ข้อมูลอยู่ในลิงก์ `#r=` ไม่ผ่านเซิร์ฟเวอร์)
- 👥 แชร์ตารางเรียน วันสอบ และงานที่ต้องส่งให้เพื่อนในชั้น (ลิงก์ `#t=` หรือวางลิงก์ในแอป)
- เตือนสำรองข้อมูลทุก 30 วัน
- ลูกเล่นเคลื่อนไหว: ทรายไหลในโลโก้ แตะโลโก้พลิกนาฬิกาทราย การ์ดเอียง 3 มิติ เม็ดทรายตอนติ๊ก (ปิดได้ในหน้าตั้งค่า)
- 🗓️ ตารางเรียนแต่ละเทอม: เก็บตารางเทอมเก่าไว้ดูย้อนหลัง และคัดลอกมาใช้เทอมใหม่ได้
- 🎓 ผลการเรียน: ใส่เกรดทุกเทอม คำนวณ GPA/GPAX วิเคราะห์วิธีอ่านเทียบกับเกรด และปรับแผนเทอมหน้าให้อัตโนมัติเมื่อใส่วิชาเทอมใหม่ · ปิดเทอมแล้วเริ่มเทอมใหม่
- 🎓 สอบใบประกอบวิชาชีพ (PLE): ปฏิทินสอบ เตือนในหน้าแรก และใส่การสอบเป็นวิชาในแผนอ่าน
- 📰 ข่าวสารในแอป + ลิงก์เว็บคณะเภสัชศาสตร์และสภาเภสัชกรรม
- สำรองและย้ายข้อมูล (รหัส S2P2: แบบบีบอัด สั้นพอส่ง LINE / ไฟล์ .json / แชร์ไฟล์) · ยังนำเข้ารหัสเก่า S2P1: ได้ · ติดตั้งลงหน้าจอโฮม เปิดได้แม้ออฟไลน์
- ข้อมูลการเรียนเก็บในเครื่องของผู้ใช้เท่านั้น

## กฎสำคัญเวลาแก้แอป
- **ห้ามเปลี่ยนชื่อ `tiw20-v2`** ใน `index.html` เป็นที่เก็บข้อมูลของผู้ใช้ เปลี่ยนแล้วข้อมูลทุกคนจะหาย
- **แก้ `index.html` ทุกครั้ง ต้องเปลี่ยนเลขเวอร์ชัน 2 ที่ให้ตรงกัน**
  - `const CACHE = 'sand2pharm-v30'` ใน `sw.js`
  - `const APP_VER='v30'` ใน `index.html` (เลขที่แสดงท้ายแอป) และ `APP_DATE`
- ผลการเรียนทุกเทอมเก็บใน `terms` ของข้อมูล `tiw20-v2` (ติดไปกับรหัสสำรองข้อมูลด้วย)
- รายงานที่ผู้ปกครองบันทึกไว้ เก็บแยกในคีย์ `sand2pharm-parent`
- `sw.js` ต้องลบเฉพาะแคชที่ขึ้นต้นด้วย `sand2pharm-` เพราะอยู่โดเมนเดียวกับ Sea To University
- **ห้ามลบหรือแก้สคริปต์ตัวนับผู้ใช้** (`<script>` ก้อนสุดท้ายก่อน `</body>`) และข้อความ "ความเป็นส่วนตัว" ท้ายแอป

- ใช้เซิร์ฟเวอร์เดียวกับ KAOWIN และ Sea To University (`kaowin-challenge.weerayoot766.workers.dev`) แยกด้วย `app:'sand'`
- วันละครั้งตอนเปิดแอป ส่งรหัสเครื่องที่สุ่ม วันที่เริ่มใช้ ประเภทเครื่อง และว่าติดตั้งเป็นแอปหรือไม่ ไม่มีชื่อและข้อมูลการเรียน
- ดูสถิติ: แตะเลขเวอร์ชันท้ายแอป 5 ครั้ง แล้วใส่รหัสเดียวกับ KAOWIN

## ลงข่าวใน `news.json` (แก้แค่ไฟล์นี้ ไม่ต้องเปลี่ยนเวอร์ชัน)
```json
{
  "id": "ชื่อเรียกข่าว-ห้ามซ้ำ",
  "text": "ข้อความข่าว",
  "start": "2026-11-20",
  "end": "2026-12-12",
  "type": "news",
  "hot": false,
  "link": "https://...",
  "linkText": "อ่านต่อ"
}
```
- `type` กำหนดสีของข่าว: `feature` ใหม่ (เขียว) · `tip` ทิป (ฟ้า) · `event` กิจกรรม (ส้ม) · `ple` สอบใบประกอบ (ม่วง) · `news` ข่าวทั่วไป (สีวนไปเรื่อย ๆ) · ไม่ใส่ก็ได้ แอปเดาจากคำขึ้นต้น “ใหม่” / “ทิป”
- ข่าวขึ้นเองตั้งแต่ `start` และหายเองหลัง `end` · `hot: true` = ป้าย "ด่วน" สีส้ม
- `link` และ `linkText` ไม่ใส่ก็ได้
- รายชื่อเว็บคณะ: ถ้าใส่ `"links": [{"name": "คณะ...", "url": "https://...", "note": "คำอธิบายสั้น"}]` แอปจะใช้รายชื่อนี้แทนรายชื่อที่ติดมากับแอป (ปล่อย `[]` ไว้ = ใช้รายชื่อเดิม)
- ระวังเครื่องหมาย `,` ระหว่างข่าว และ `"` ให้ครบ ถ้าไฟล์ผิดรูปแบบ แอปจะไม่แสดงข่าว (แต่แอปยังใช้งานได้ปกติ)

## อัปเดตปฏิทินสอบใบประกอบ (PLE)
ปฏิทินปี 2569–2570 ติดมากับแอปแล้ว (จากเว็บศูนย์สอบ plecenter.org) ถ้าศูนย์สอบเลื่อนวันหรือประกาศปีใหม่ ใส่ใน `news.json` ได้เลย จะใช้แทนปฏิทินที่ติดมากับแอป:
```json
"ple": [
  ["2028-03-18", "", "exam", "สอบ PLE-CC2 (สอบปฏิบัติ)", "PLE-CC2"],
  ["2028-03-19", "2028-03-20", "exam", "สอบ PLE-CC1 (ข้อเขียน 14:00–17:00)", "PLE-CC1", "14:00-17:00"],
  ["2028-01-20", "2028-01-25", "apply", "สมัครสอบ PLE-CC1/CC2"]
]
```
ลำดับในแต่ละแถว: วันเริ่ม, วันสิ้นสุด ("" = วันเดียว), ชนิด (`reg` ลงทะเบียน / `apply` สมัคร / `exam` สอบ / `result` ประกาศผล), ข้อความ, รหัสสอบ (ใส่เฉพาะแถวที่ให้นักศึกษากดใส่ในแผนอ่านได้), เวลาสอบ
